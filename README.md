# 🎲 Farkle 3D — Игра в кости «10000»

Интерактивная 3D-версия классической игры в кости Farkle (также известной как «10000»).

## 🎮 О игре

**Farkle (10000)** — это азартная игра в кости, где игроки по очереди бросают 6 кубиков, набирая очки за различные комбинации. Цель игры — первым набрать 10 000 очков.

### Правила игры

#### Комбинации и очки

| Комбинация | Очки |
|------------|------|
| **1** (по отдельности) | 100 |
| **5** (по отдельности) | 50 |
| **Три 1** | 1 000 |
| **Три 2** | 200 |
| **Три 3** | 300 |
| **Три 4** | 400 |
| **Три 5** | 500 |
| **Три 6** | 600 |
| **Четыре одинаковых** | ×2 от трёх |
| **Пять одинаковых** | ×4 от трёх |
| **Шесть одинаковых** | ×8 от трёх |
| **Стрит (1-2-3-4-5-6)** | 1 500 |
| **Три пары** | 750 |

#### Ход игры

1. **Бросок**: Игрок бросает все 6 кубиков
2. **Выбор**: Игрок выбирает кубики с очками (минимум один)
3. **Решение**:
   - **В банк**: Забрать накопленные очки в общий счёт (ход переходит)
   - **Продолжить**: Бросить оставшиеся кубики для набора большего количества очков
4. **Фаркл (Farkle)**: Если в броске нет очков — игрок теряет все очки за этот ход

#### Условия победы

Игра заканчивается, когда один из игроков набирает **10 000 или более очков**. В этом случае остальные игроки получают по одному дополнительному ходу, чтобы попытаться обойти лидера.

## 🚀 Запуск

Откройте файл `farkle-3d.html` в любом современном браузере:

```bash
# Вариант 1: Просто откройте файл
open farkle-3d.html          # macOS
xdg-open farkle-3d.html      # Linux
start farkle-3d.html         # Windows

# Вариант 2: Через локальный сервер
python3 -m http.server 8080
# Затем откройте http://localhost:8080/farkle-3d.html
```

## 🎮 Как играть

1. **Настройка игры**: Добавьте игроков через панель управления
2. **Начало хода**: Нажмите кнопку **«Бросить»**
3. **Выбор кубиков**: Кликните на кубики, которые хотите сохранить
4. **Принятие решения**:
   - **«В банк»** — забрать очки и завершить ход
   - **«Бросить ещё»** — рискнуть и продолжить набор очков
5. **Победа**: Первый до 10 000 очков побеждает!
